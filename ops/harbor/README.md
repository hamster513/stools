# Harbor для проверки образов контейнеров в STools

Здесь лежит пример конфигурации Harbor с встроенным сканером Trivy. STools
подключается к Harbor под учётной записью-роботом, читает готовые отчёты Trivy и
показывает уязвимости образов в модуле VM («Образы контейнеров») по той же шкале
риска, что и уязвимости хостов. Сам Harbor в compose STools не входит: это
отдельная установка, у заказчика она обычно уже есть. Файл
`harbor.yml.example` нужен, чтобы поднять тестовый экземпляр рядом со стендом.

Поднять Harbor: скачайте онлайн-установщик `harbor-online-installer-v2.15.4.tgz`
со страницы релизов goharbor/harbor, распакуйте его, скопируйте
`harbor.yml.tmpl` в `harbor.yml`, приведите ключи к значениям из
`harbor.yml.example` (пароли — свои, вместо `CHANGE_ME`) и запустите
`./install.sh --with-trivy`. На Docker Desktop для Mac установщику нужна
правка `docker-compose.yml` — она описана в `docs/vm/harbor.md`.

Подключить к STools: создайте в Harbor проекты с автоматическим сканом при
push и робота системного уровня с правами только на чтение, затем в
«Настройки → VM → Harbor» введите адрес, имя робота и его секрет. Робот, его
права, адрес Harbor с точки зрения контейнера API, HTTPS и ограничения первой
версии — в `docs/vm/harbor.md`.
