# Цепочка TLS БДУ ФСТЭК

`bdu-ca.pem` используется только для заданий источников с точным hostname `bdu.fstec.ru`; системное хранилище доверия и остальные источники не изменяются. Проверки hostname, срока действия и подписи TLS остаются включены.

Корень загружен с [официального CDN Госуслуг](https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt), описание установки — [Госуслуги](https://www.gosuslugi.ru/crt). SHA-256 сертификата (DER): `D26D2D0231B7C39F92CC738512BA54103519E4405D68B5BD703E9788CA8ECF31`.

Промежуточный сертификат `subca_ssl_rsa2024.crt` взят из AIA сертификата БДУ: `http://nuc-cdp.digital.gov.ru/cdp/subca_ssl_rsa2024.crt`. Его подпись проверена официальным корнем; затем проверена цепочка сертификата `*.fstec.ru`. Это не самостоятельный источник доверия. При обновлении цепочки сначала повторить `openssl verify -CAfile root.pem intermediate.pem` и проверку leaf с `-untrusted intermediate.pem`, затем тест загрузки bundle.

Исправление доверия TLS не отменяет HTTP-ограничения издателя: ответы 403 и антибот-страницы остаются ошибками доступа.
