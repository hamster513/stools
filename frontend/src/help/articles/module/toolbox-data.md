## Что это

Просмотр структурированных данных и логов: JSON, JSONL, CSV и XML. Вставьте текст или откройте файл UTF-8 размером до 1 МиБ. Обработка происходит в браузере после нажатия кнопки; данные не отправляются на сервер и не сохраняются. Изменение ввода или формата очищает предыдущий результат.

## Как читать

**Анализировать A** форматирует первый документ. JSON-массив превращается в строки таблицы; объект — в одну строку; скаляр, вложенный массив или `null` — в строку с полем `value`. JSONL принимает отдельный JSON на каждой непустой строке и сообщает номер ошибочной строки. CSV использует первую строку как уникальные непустые заголовки и проверяет число полей. Кавычки, разделители внутри кавычек, удвоенные кавычки и переносы строк внутри ячеек поддерживаются.

Числа JSON/JSONL должны сохранять десятичное значение при преобразовании в JavaScript Number. Целые принимаются только от −9007199254740991 до 9007199254740991; переполнение, исчезновение очень малых чисел, потеря десятичных цифр и отрицательный ноль отклоняются с ошибкой. Эквивалентные записи `1.0` и `1e0` принимаются как `1`. Длинные идентификаторы и значения, требующие большей точности, передавайте строками, например `"9007199254740993"`. Пустая строка данных CSV с единственным полем сохраняется как `""`, в том числе в конце документа.

Выберите поля и введите текстовый фильтр, затем нажмите **Применить поля и фильтр**. Поиск идёт только по выбранным полям без учёта регистра. Таблица показывает до 200 строк и 30 столбцов; выбор доступен среди первых 100 полей. Ячейки сокращаются до 200 символов. Счётчик показывает полное количество подходящих строк.

Предпросмотр форматированного текста ограничен 65 536 символами. **Скопировать** и **Скачать весь документ A** сохраняют полный форматированный документ независимо от фильтра и полей таблицы. Форматированный результат ограничен 8 МиБ, вложенность — 128 уровнями.

**Сравнить A и B** сравнивает два документа выбранного формата. Для JSON порядок ключей объектов не учитывается, порядок массива учитывается; путь различия записан как JSON Pointer. Для JSONL, CSV и XML сравниваются строки форматированного текста: общий префикс и суффикс исключаются, оставшиеся строки сопоставляются по позиции. Это простое построчное сравнение: вставка внутри большого изменённого блока может показываться как несколько замен.

Добавления, удаления и изменения подписаны отдельно. Показываются первые 200 различий и до 500 символов каждого значения, пути ограничены 1024 символами; счётчик учитывает все различия. Для XML нет табличного представления: документ показывается только как текст. DTD и объявления ENTITY отклоняются, внешние ресурсы не загружаются, смешанное содержимое сохраняется. XML сравнивается текстово, поэтому порядок атрибутов может давать различие.

## Как настроить

Выберите формат вручную. Для CSV выберите запятую, точку с запятой, табуляцию или вертикальную черту. Параметры действуют одновременно для A и B. Серверных настроек нет.
