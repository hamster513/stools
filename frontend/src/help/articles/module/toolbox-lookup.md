## Что это

Единый локальный поиск по IP, имени хоста/FQDN, домену или CVE. Запрос выполняется по собранным данным STools, без внешних сервисов, DNS-запросов и языковых моделей. История запросов не сохраняется. В журнал действий попадает сам факт поиска без искомого значения.

## Как читать

Введите один идентификатор и нажмите «Найти» или Enter. Поиск точный, без учёта регистра, без масок и поиска по части строки. Завершающая точка DNS-имени удаляется. «Автоматически» распознаёт IP и CVE; остальные значения проверяет как имя хоста и домен. Выберите «Имя хоста / FQDN» или «Домен», чтобы убрать неоднозначность. Короткое имя может совпасть у разных устройств — записи не объединяются.

Результаты сгруппированы по источникам. В карточке — основание совпадения, факты, источник, дата данных и ссылка. Неизвестная дата показана явно. Время поиска не является временем сбора данных. В каждом разделе показано до 20 записей, наличие остальных отмечается; уточните запрос или перейдите в исходный модуль.

- **Assets:** действующие карточки активов; IP также проверяется в текущих наблюдениях источников. Вторичный IP может отличаться от основного IP карточки.
- **AD:** DNS/NetBIOS-домены и наблюдения компьютеров после синхронизации AD → Assets. Это не поиск всех объектов AD. IP в наблюдении AD может отсутствовать. Ссылка компьютера открывает его домен.
- **AV:** последний по дате сбора снимок каждого сервера, состояние защиты и угрозы в этом снимке. Ссылка открывает карточку хоста.
- **VM:** хосты и пары хост–CVE из импорта. В VM могут отсутствовать хосты без CVE. Решения аналитика и статусы находок смотрите в карточке VM.
- **CVE:** сведения из локальной витрины VM или NVD, даже если CVE не сопоставлена с инфраструктурой.
- **Образы:** находки CVE в пакетах образов. Это не свидетельство запуска образа на конкретном сервере.
- **Публикации:** связи с точной CVE в действующей загрузке коллектора; отозванные публикации исключены. Ссылка открывает карточку угрозы. Произвольные IP и домены в текстах публикаций здесь не ищутся.

Права чтения проверяются отдельно для каждого модуля. Для недоступного источника не возвращаются ни записи, ни их количество. «Не применимо» означает, что источник не проверялся для этого типа запроса; «Проверено без совпадений» — запрос выполнен, но точных совпадений нет в загруженных данных.

Упоминание в публикации, наличие CVE в справочнике и находка сканера — разные свидетельства. Ни одно само по себе не доказывает компрометацию. Пустая выдача не означает отсутствие угрозы: проверьте идентификатор, доступ и синхронизации.

## Как настроить

Отдельного подключения у инструмента нет. Настройте синхронизации исходных модулей и права чтения в ролях. Для поиска компьютеров AD должна выполняться синхронизация Assets. Для сведений о CVE загрузите справочники VM, для публикаций — данные коллектора угроз.
