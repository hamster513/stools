## Что это

Калькулятор адресов IPv4. По адресу с маской он показывает сеть, широковещательный адрес, диапазон узлов, обратную маску и вид адреса. Пригодится, чтобы проверить правило межсетевого экрана, разобрать сеть из выгрузки или понять, частный ли адрес в событии. Всё считается в браузере. IPv6 калькулятор не считает.

## Как читать

Адрес вводят в одно поле, маску можно записать по-разному: `10.0.0.1/24`, `10.0.0.1 255.255.255.0`, `10.0.0.1/255.255.255.0`, `10.0.0.1 24`. Без маски адрес считается одиночным, `/32`. Результат пересчитывается при вводе.

| Строка | Что в ней |
|---|---|
| Маска | Маска точками и префикс |
| Обратная маска | Wildcard: так маску пишут в ACL Cisco и правилах OSPF |
| Сеть, Широковещательный | Первый и последний адрес сети |
| Первый узел, Последний узел, Узлов | Диапазон адресов для узлов. У `/31` два узла (канал точка-точка, RFC 3021), у `/32` один адрес |
| Вид адреса | Частный (RFC 1918), CGNAT (RFC 6598), loopback, link-local, multicast, документация (RFC 5737), зарезервированный или публичный |
| Класс | A–E, только для справки: классовая адресация устарела |
| Целым числом, Шестнадцатерично | Так адрес хранят некоторые базы и SIEM |

Ниже двоичный вид адреса, маски и сети. Биты сети выделены, биты узла приглушены. Кнопка «Скопировать сеть» кладёт в буфер сеть с префиксом, например `192.168.1.0/24`.

Маска с разрывами (`255.0.255.0`) — ошибка: единицы в маске должны идти подряд слева. Октеты с ведущими нулями читаются как десятичные: `010` — это 10, а не 8.

## Как настроить

Настраивать нечего.
