## Что это

Одно задание [обезличивания](help:scrubbing) от начала до конца: сканирование, предпросмотр найденного, очистка и результат. Сначала STools только ищет; заменяет значения кнопка «Очистить» — после того как вы посмотрели находки.

## Как читать

**Новое задание** открыто только аналитику и администратору. Вкладка «Файл» — до 200 МБ, распакованное содержимое до 512 МБ: json, json.gz, gz, zip (и вложенные), csv, txt, log, xml, conf, ini, yaml. Офисные документы и pdf не поддерживаются; файл с другим расширением читается как текст, а двоичный сервер отклонит. Вкладка «Текст» — до 1 МБ. Галочка «Учётные записи из последнего снапшота AD» добавляет к поиску логины пользователей домена. «Сканировать» открывает карточку.

**Шапка карточки**: номер, вид, статус, имя файла, размер, кто и когда запустил. Вставленный текст уходит на сервер файлом, поэтому в шапке он называется `text.txt`. Пока задание идёт, виден его ход, а у аналитика — кнопка «Отменить»; уходить со страницы можно, задание идёт на сервере.

**Находки** — по одной строке на уникальное значение, группами: секреты, слова, учётные записи, хосты, домены, SID, IPv4, IPv6, MAC; у группы — «включено / всего». Колонки: «Заменять», значение, [псевдоним](help:alias), сколько вхождений, контекст (кусок текста вокруг, до трёх в подсказке), первый файл. Метка «авто» — значение найдено не по словарю, а поиском по виду: проверьте его. Без галочки сразу стоят найденное только авто-поиском и адреса, похожие на номер версии. Поиск по значению, по 200 строк на страницу.

Аудитор видит находки без контекстов, а у секретов — без значений.

**Результат** успешной очистки: кнопки скачивания — файл того же типа, «Отчёт» (счётчики по категориям, без настоящих значений) и «Соответствия (csv)» — псевдонимы этого задания без секретов. Таблица: категория, найдено (уникальных значений), заменено (вхождений); строка «Файлов: N, пропущено (не текст)».

## Как настроить

Правит аналитик, пока задание не очищено.

- Снимите или поставьте галочки, в том числе для всей страницы.
- Поправьте псевдоним, если он ещё не записан в таблицу соответствий; записанный меняется только через «забыть». Псевдоним, занятый другим значением или содержащий настоящее значение, сервер отвергнет. Метки секретов не правятся.
- «Добавить слово» — своё слово (фамилия, проект) для этого задания. Слова уходят вместе с «Сохранить», вход сканируется заново, и страница пишет, сколько новых находок они дали.
- «Сохранить · N» отправляет правки, «Сбросить правки» их отменяет. «Очистить» доступна только без несохранённых правок.

**Очистка** заменяет отмеченные значения и записывает новые псевдонимы в таблицу соответствий, затем проверяет себя: результат сканируется заново. Если в нём осталось хоть одно отмеченное значение, задание кончается ошибкой, результат удаляется, а таблица не меняется — поправьте находки и нажмите «Очистить» снова.

«Экспорт» сохраняет находки в CSV или XLSX с настоящими значениями, включая секреты, но без контекстов.

Файлы хранятся столько дней, сколько задано в [Настройках ToolBox](help:toolbox-settings). Потом они удаляются вместе с находками, скачать результат больше нельзя; счётчики по категориям остаются.
