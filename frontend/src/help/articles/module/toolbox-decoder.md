## Что это

Последовательные преобразования строк и байтов. Команды не исполняются, данные не отправляются на сервер и не сохраняются. Можно работать с текстом или загрузить бинарный файл.

## Как читать

Выберите операцию и нажмите «Применить шаг». Результат становится входом следующего шага. «Отменить шаг» возвращает предыдущие байты. Изменение исходной строки сбрасывает всю цепочку.

Доступны Base64 и Base64URL, percent-encoding URL, Hex, чтение UTF-8/UTF-16 LE/BE, разбор JSON-строки, JWT, PowerShell EncodedCommand и распаковка gzip/deflate с заголовком zlib. Например: Base64 → UTF-16 LE для команды PowerShell или Base64 → gzip → UTF-8 для сжатого текста. URL decode сохраняет знак `+`, это не декодер HTML-форм.

Для PowerShell вставьте Base64 либо команду с `-EncodedCommand` / `-enc`. JWT показывает header и payload; подпись, срок действия и доверие к токену не проверяются. JSON-строка должна быть заключена в двойные кавычки.

Результат, который нельзя прочитать как UTF-8, показывается в Hex; выберите нужную кодировку или скачайте байты. В предпросмотре до 128 Ки символов текста или 4096 байт Hex; скачивание содержит полный результат. Лимит входа и каждого шага — 1 МиБ, цепочка — до 12 шагов. Распаковка останавливается при превышении лимита.

## Как настроить

Подключений и ключей нет. Для распаковки нужен браузер с DecompressionStream; если API недоступен, инструмент покажет ошибку.
