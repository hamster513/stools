## Что это

Локальная проверка X.509-сертификатов. Вставьте PEM или загрузите PEM/DER, при необходимости укажите DNS-имя либо IP-адрес и нажмите **Анализировать**. Обработка выполняется на сервере STools: сертификаты не сохраняются, не передаются внешним сервисам и не загружаются по сети. Приватные ключи не принимаются.

Каждое поле и файл ограничены 1 МиБ; в PEM допускается до 16 сертификатов. В основной цепочке первым должен быть серверный сертификат, затем промежуточные. DER содержит один сертификат, при вставке текста выберите «DER в Base64».

## Как читать

Результат разделяет три проверки: разбор формата, совпадение имени с SAN и доверие TLS-цепочке. Успешный разбор не подтверждает доверие. Без отдельно заданных корней результат всегда «доверие не проверено» — даже для самоподписанного сертификата или корня в основном PEM-поле.

Для каждого сертификата показаны Subject, Issuer, SAN, сроки действия UTC, серийный номер в hex, алгоритмы ключа и подписи, отпечатки SHA-256 и SHA-1. Отпечаток SHA-1 приведён для сопоставления со старыми системами. Кнопки рядом со значениями копируют их в буфер.

Имя сверяется только с SAN: DNS поддерживает wildcard в целой крайней левой метке (`*.example.org` подходит для `a.example.org`, но не `a.b.example.org`), IP — только точное совпадение с IP SAN. CN не используется как запасное имя.

Проверка доверия применяет строгую политику TLS-сервера X.509 на текущее время UTC. Ошибка может означать неверное имя, срок, недостающий промежуточный сертификат, чужой корень, некорректную подпись или ограничения сертификатов. CRL/OCSP и отзыв сертификатов не проверяются. Изменение ввода убирает предыдущий результат; новый запрос выполняется по кнопке.

## Как настроить

Для проверки TLS-цепочки укажите DNS-имя/IP и вставьте либо загрузите доверенные корни PEM в отдельное поле. Системное хранилище доверия не используется. Промежуточные сертификаты добавляйте в основное поле после серверного. Корни выбирайте из доверенного источника: результат подтверждает доверие только относительно предоставленного набора.
