## Что это

Что ToolBox ищет и заменяет сверх встроенного — свои слова и дополнительные подсети — и сколько хранить файлы заданий [обезличивания](help:scrubbing). Видит и меняет настройки только администратор модуля: в словах и подсетях записаны настоящие значения. Аналитик на этой странице видит только пояснение, аудитор её не открывает.

## Как читать

Три блока: «Слова», «Подсети», «Хранение файлов». Списки показаны компактно, по паре на строку; длинный список прокручивается внутри блока. Одна кнопка «Сохранить» внизу сохраняет всё сразу.

## Как настроить

### Слова

[Открыть](/settings/toolbox#words). Названия проектов, площадок, систем — всё, чего нет в словарях модулей. Слово ищется как часть слова и без учёта регистра, поэтому короткое слово заменится и внутри других слов. [Псевдоним](help:alias) задавать необязательно: без него он будет вида `word-NNNN`.

- Добавляйте по одному: слово, псевдоним, «Добавить».
- Или «Вставить списком»: по паре на строку, `PROJECT = PRJ-A`; без `=` — только слово. Повтор слова, которое уже есть, не дублирует строку, а меняет её псевдоним.
- Щелчок по слову или псевдониму правит его на месте: `Enter` — принять, `Esc` — отменить. Крестик удаляет строку.

Повтор слова или псевдонима в списке сервер не примет.

### Подсети

[Открыть](/settings/toolbox#subnets). Сети модуля Assets ToolBox учитывает сам: каждая сдвигается целиком внутри своей частной зоны. Здесь — дополнительные пары, где адреса первой подсети заменяются адресами второй: `10.10.0.0/16 = 10.210.0.0/16`. Длины префиксов в паре должны совпадать, вторая подсеть обязательна: строки без неё при вставке списком пропускаются. Остальные адреса, которые не попали ни в одну сеть, получают псевдоним по ключу установки.

### Хранение файлов

[Открыть](/settings/toolbox#retention). «Срок хранения, дней» — от 0 до 3650, по умолчанию 7. Раз в сутки файлы завершённых заданий — исходный, результат и отчёт — удаляются через столько дней после завершения; 0 — при ближайшей очистке. Вместе с файлами из базы удаляются находки задания: настоящие значения, контексты и секреты. Строка задания, счётчики по категориям и таблица соответствий остаются. Удалить задание раньше срока можно вручную в списке [Очистка файлов](help:toolbox-overview).

**Ключ установки.** Псевдонимы адресов считаются по секретному ключу, который сервер создаёт сам при первом обращении. На странице его нет, наружу он не отдаётся; вместе с таблицей соответствий он должен попадать в резервную копию базы.
