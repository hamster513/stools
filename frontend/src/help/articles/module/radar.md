## Что это

Радар собирает сведения о пути к приложению. На первом этапе доступны конфигурации nginx: виртуальные серверы, URL, backend-серверы, локальные приложения, статические файлы и ограничения доступа. Модуль заменяет прежнюю заглушку FW.

Конфигурация не подтверждает внешнюю доступность. Сервисы с внешними и внутренними адресами показываются вместе; до сопоставления с внешними наблюдениями и сетевыми правилами доступ извне отмечен «Не установлен». ScanFactory и NetTrace в этом этапе ещё не подключены.

## Как настроить

В «Настройки → Радар» выберите сразу несколько файлов **имя-сервера.conf**, нажмите «Предварительный просмотр», проверьте результаты и ограничения, затем «Сохранить снимки». Поддерживается полная текстовая выгрузка `nginx -T` с разделителями `# configuration file …:`. Include раскрываются только из присутствующих в выгрузке файлов. STools не обращается к файловой системе nginx и не выполняет конфигурацию.

Лимиты: 32 файла в пачке, 2 МиБ на файл и 16 МиБ на пачку. Текст — UTF-8. При ошибке любого файла пачка не сохраняется; предыдущие снимки остаются доступны. Повторная загрузка текущего неизменившегося файла не создаёт снимок. Если настройка сложна настолько, что превышен лимит раскрытия, импорт отклоняется с объяснением.

Оригинал хранится зашифрованным штатным ключом STools. Для восстановления базы вместе с оригиналами необходим прежний `STOOLS_SESSION_SECRET`. В интерфейсе показано ограниченное представление директив: комментарии, произвольные значения, значения заголовков и тела ответов скрыты. Это представление нельзя использовать для восстановления рабочего nginx.

## Как читать

Найдите сервер по имени, домену, адресу или backend. Откройте снимок и выберите виртуальный сервер.

- **Маршруты:** сворачиваемые записи location с назначением и настройками; `(server)` — контекст сервера, а не дополнительный URL. Вложенные location сохраняют путь родительских блоков.
- **Настройки:** явно заданные и унаследованные директивы с файлом и строкой источника. Неуказанные значения nginx по умолчанию не подставляются.
- **Связи:** схема выбранного маршрута слева направо. Она показывает один конфигурационный участок nginx → backend, а не полный вычисленный сетевой путь. Все члены upstream показываются с их параметрами; `down` не означает активное соединение.
- **Источники:** структурированное представление директив с поиском и номерами строк исходных файлов.
- **История:** последние 50 снимков; при открытии старого снимка показываются именно его настройки.

`localhost` и loopback относятся к серверу из имени файла. Совпадение с Assets показывается только при наличии права чтения Assets и одном точном совпадении имени/FQDN. По коротким именам разных доменов автоматическое объединение не выполняется.

Время импорта не равно времени сбора. Переменные в backend, отсутствующие include, контексты stream/mail и условные переходы отмечаются как ограничения. Парсер не вычисляет обработку произвольного HTTP-запроса, DNS, сетевую доступность или возможность эксплуатации CVE.

## Доступ

Для существующих пользовательских ролей доступ к новому модулю по умолчанию закрыт. Администратор выдаёт необходимые права области «Радар» через настройки доступа.
