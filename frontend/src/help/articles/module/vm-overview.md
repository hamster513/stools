## Что это

Модуль берёт из MaxPatrol VM хосты и найденные на них уязвимости ([CVE](help:cve)), дополняет их открытыми [справочниками](help:vm-references) и считает для каждой пары «хост — CVE» [риск](help:vm-risk) от 0 до 100: что чинить первым. Каждая пара — [находка](help:finding) со [статусом](help:finding-status), исполнителем и сроком. Страница «Обзор» — сводка: сколько уязвимостей, что выше порога, какой патч снимет больше всего риска и чего не хватает данным. Отдельно модуль показывает [образы контейнеров](help:vm-images) из [Harbor](help:harbor) с их уязвимостями; в сводку обзора они не входят.

## Как читать

Плитки и строки списков на обзоре — ссылки в отфильтрованный список [Уязвимости](help:vm-vulns). Справа вверху — когда и откуда был последний импорт.

- **Первый ряд**: хосты с уязвимостями, пары хост — CVE, уникальные CVE и «Выше порога 80» — пары с риском не ниже порога из настроек (80 по умолчанию).
- **Второй ряд**: находки по статусам — открытые, в работе, просроченные, «[Принят риск](help:risk-accept)».
- **Распределение по шкале риска** — одна полоса с долями четырёх уровней (низкий, средний, высокий, критический) и границы уровней из настроек. Под ней — сколько пар с CVE из каталога [KEV](help:kev), то есть уже эксплуатируемых в реальных атаках.
- **CVE, закрывающие больше всего** — десять CVE с наибольшей суммой риска по всем хостам: патч одной из них снимает больше всего. Рядом — число хостов, [CVSS](help:cvss) и пометка «эксплойт».
- **Хосты с наибольшим риском** — десять хостов по сумме риска всех их уязвимостей, с [зоной](help:vm-zone) и критичностью.
- **Данные** — из-за чего риск посчитан неточно: дата и объём каждого справочника (старше 30 дней — подсвечен), CVE без записи в NVD (национальной базе уязвимостей США), CVE без [EPSS](help:epss) (взято значение по умолчанию), зоны без разметки, итог последнего импорта.

Пары, распределение, «выше порога» и KEV считают только находки с учитываемыми статусами: по умолчанию «Принят риск», «Ложное срабатывание» и «Устранена» не в счёт. Списки самых опасных CVE и хостов строятся по всем парам.

Пока импорта не было, вместо обзора написано «Уязвимостей ещё нет» и есть кнопка «Настроить импорт».

**Страницы модуля** в меню слева:

- «Обзор» — эта страница;
- [Уязвимости](help:vm-vulns) — все пары хост — CVE с фильтрами и карточкой расчёта риска;
- [Образы контейнеров](help:vm-images) — образы из Harbor и их уязвимости с рисками по той же формуле;
- [Задачи](help:vm-jobs) — импорт, справочники, пересчёт, синхронизация Harbor и массовая смена статусов, которые идут в фоне.

## Как настроить

**Откуда данные.** Хосты и CVE приходят импортом, оба пути — в [Настройки Vulnerability Management](help:vm-settings): кнопка «Импортировать из VM» забирает данные по API MaxPatrol VM, а зона загрузки принимает CSV-экспорт MaxPatrol VM. Каждый импорт заменяет данные целиком; разметка зон и справочники остаются. Расписания у импорта нет: данные обновляются, когда их импортировали.

Справочники EPSS, NVD, ExploitDB, Metasploit, CISA KEV и разметку CVE → ATT&CK администратор модуля скачивает из сети или загружает файлами. После импорта, загрузки справочника, обновления модели или разметки зон риск пересчитывается сам. Исключение — справочник CTID (Center for Threat-Informed Defense, исследовательский центр при MITRE): он обновляет только слой матрицы ATT&CK.

Пары с риском не ниже отдельного порога и с учитываемым статусом попадают в [матрицу ATT&CK](help:attack-overview) как экспозиция. Когда был последний импорт и насколько свежи справочники, видно на странице [Данные и загрузки](help:data-status): импорт старше семи дней и справочник старше 30 дней считаются устаревшими.
