## Что это

Группы как отдельный вид [актива](help:asset): доменные группы из выгрузки AD и локальные группы хостов из MaxPatrol VM (у Windows — с SID, у Linux — с описанием «GID n»). Карточка группы показывает, кто в неё входит прямо и через вложенные группы, куда входит она сама и какие права на хостах это даёт — по факту и по политике. Данные — из последней синхронизации.

## Как читать

**Колонки**: имя, домен или компьютер (у локальной группы — имя хоста ссылкой на карточку актива), вид (локальная, доменная), число прямых участников, источники, SID, описание. Доменная группа, которую VM видит участником локальных групп, а в выгрузках AD её нет, помечена «нет в AD».

**Поиск** — по имени и SID; клавиши `/`, `j`, `k`, `Enter`, `Esc`. **Фильтры** — вид, источник, есть ли прямые участники, состояние. Без выбора состояния показаны только живые группы, пропавшие — выбором «пропавшие». Ссылка «локальные группы хоста» из карточки актива открывает список с фильтром по хосту. **«Экспорт»** — CSV или XLSX с теми же колонками.

**Карточка группы** выезжает справа. Шапка: имя, домен или хост, вид, SID, описание, источники, когда видна впервые и последний раз, дата пропажи; у локальной — дата выгрузки групп из VM. Ниже блоки:

- «Состав» — прямые участники: пользователи, группы и компьютеры ссылками в свои карточки, встроенные субъекты с пояснением, неизвестные; пометка «основная группа» — участник через основную группу учётки. Больше 1000 участников — «показаны 1000 из N». У локальной группы Linux основная группа пользователя в составе не видна, и карточка это оговаривает.
- «Полный состав» — по кнопке: пользователи и компьютеры через все вложенные группы; у каждого кратчайшая цепочка «через …» и число путей. Внизу тупики — неизвестный участник, группа без записи, «нет в AD». Циклы вложенности не мешают: каждая группа раскрывается один раз.
- «Куда входит» — доменные группы, прямо и через вложенность, и локальные группы на хостах.
- «Права» — два отдельных списка. «По факту (VM)» — в каких локальных группах хостов группа состоит по данным VM, сводом вроде «Administrators на 120 хостах · через Helpdesk». «По политике (GPO)» — записи Restricted Groups и GPP (Group Policy Preferences): локальная группа, имя GPO, способ, действие, хосты; пометка «фильтр безопасности» значит, что политика может действовать не на всех хостах списка. Оговорки разбора GPO — под списком.

## Как настроить

Страница только для чтения: правок у групп нет. Состав обновляет синхронизация с модулями AD и VM. Пропавшие локальные группы определяются только по полной выгрузке семейства ОС (Windows, Linux). Если выгрузка групп из VM не прошла, оказалась не того формата или пустой при непустой прежней, остаётся прежняя; с лимитом записей в подключении VM выгрузка неполная, и пропавшими по ней группы не считаются.
