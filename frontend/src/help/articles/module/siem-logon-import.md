## Что это

Последний вход пользователя с определённого источника на определённое назначение. Источник — табличный список MaxPatrol SIEM; подключение общее с Rules Analyzer и Threat Hunting. Список в SIEM только читается.

Это сведения о прошлых входах, а не подтверждение активного сеанса. Если список хранит только последнее время, восстановить из него полную историю входов нельзя.

## Как настроить

1. Откройте [мастер](/settings/siem-logons). Получите каталог списков и выберите название либо введите его вручную. При нескольких конвейерах укажите ID нужного конвейера SIEM.
2. Сопоставьте поля STools с колонками списка. Обязательны пользователь, время входа и хотя бы одно поле назначения — хост или IP. Домен берётся из отдельной колонки, `DOMAIN\user` или `user@domain`. Известные псевдонимы доменов учитываются по настройкам Assets. Неиспользуемые поля оставьте пустыми.
3. Проверьте первые 20 строк. Ошибки показываются с номером строки; при наличии ошибок сохранение через мастер недоступно. Для пустого списка можно сохранить настройку, но сопоставление ещё не проверено на данных.
4. Сохраните настройку и нажмите «Импортировать сейчас». Для автоматического запуска откройте [общее расписание](/settings/schedules) и настройте задачу «Импорт авторизаций из табличного списка SIEM». Планировщик Threat Hunting не меняется.

Для примера с колонками `user`, `domain`, `src_host`, `src_ip`, `dst_host`, `dst_ip`, `_last_changed` сопоставление уже заполнено. `_last_changed` соответствует времени последней авторизации. Поддерживаются ISO 8601 с часовым поясом, Unix-секунды и Unix-миллисекунды. В интерфейсе время отображается в часовом поясе браузера.

## Повторный импорт и ошибки

Импорт читает все страницы списка. Лимит по умолчанию — 100 000 строк, настраивается от 1 до 1 000 000. Превышение лимита, ошибка чтения или некорректная строка отменяют импорт целиком; прежние данные остаются. Номер и причина ошибки видны в истории импортов.

Связка включает сервер и конвейер SIEM, название списка, пользователя с доменом, хосты и IP источника и назначения. Повторная строка обновляет последнее время входа; более старая выгрузка не уменьшает его. Разные источники сохраняются отдельно. Исчезновение строки из списка не удаляет известный прошлый вход. При смене списка или сопоставления ранее импортированные связи сохраняются.

## Как читать

В карточках пользователя и хоста появляется блок «Авторизации SIEM». Для хоста показаны входы как с него, так и на него. Пользователь связывается по домену и имени; если такой учётки ещё нет, создаётся карточка с неизвестным состоянием AD. Хосты сопоставляются с существующими активами по имени и IP. Неоднозначные совпадения не связываются автоматически; исходные сведения сохраняются в таблице импортированных входов на странице мастера.

Ручные заметки и теги, состояние учётки в AD и признаки активных сеансов не меняются. Для просмотра импортированных сведений нужны права чтения Assets; для настройки мастера — администратор SIEM.
