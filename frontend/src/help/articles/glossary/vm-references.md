## Что это

MaxPatrol VM сообщает только, какие [CVE](help:cve) найдены на хосте. Всё остальное о них STools берёт из открытых справочников:

| Справочник | Что даёт |
|---|---|
| [EPSS](help:epss) | вероятность эксплуатации в ближайшие 30 дней |
| NVD CVE (национальная база уязвимостей США) | описание, [CVSS](help:cvss) и вектор атаки; фиды по годам |
| GitHub Advisory Database | GHSA, включая записи без CVE, CVSS, официальные алиасы, пакеты и версии |
| ExploitDB | публичные эксплойты и их тип |
| Metasploit | модули фреймворка и их ранг |
| CISA [KEV](help:kev) | каталог уже эксплуатируемых уязвимостей |
| CVE → ATT&CK от CTID (Center for Threat-Informed Defense, исследовательский центр при MITRE) | какой [технике](help:technique) ATT&CK соответствует CVE — для матрицы, на [риск](help:vm-risk) не влияет |

NVD и GHSA дают критичность уязвимостей; EPSS, ExploitDB, Metasploit и KEV участвуют в оценке вероятности эксплуатации. CTID используется в матрице ATT&CK. Если метрики нет, применяется явно обозначенная подстановка формулы.

## Обновление баз

Для NVD загружаются записи, изменённые после последней успешной синхронизации, в том числе исправления старых CVE и отклонённые записи. GHSA сравнивается по точным версиям официального Git-репозитория: передаются изменённые JSON и сведения об удалениях. Отозванные advisory сохраняют своё состояние; изменения алиасов и пакетов также применяются.

EPSS, KEV, ExploitDB, Metasploit и CTID проверяются по версии HTTP-ресурса. Неизменившийся файл повторно не загружается. Если источник изменился, используется его новый снимок. Для EPSS это необходимо: [FIRST рекомендует дневной CSV для синхронизации полной базы](https://www.first.org/epss/data), а API предназначен для отдельных запросов.

Первый полный снимок задаёт исходную версию. Пакет обновлений содержит исходную и новую версии; STools проверяет их перед применением. Нельзя заменить версию источника временем загрузки файла на сервер. Повторное применение пакета не создаёт дублей, а пропуск промежуточного пакета обнаруживается.

После изменения данных пересчитывается риск. Проверка без изменений сохраняет дату загрузки и обновляет дату проверки; такую базу не считают устаревшей только из-за возраста файла. Порядок действий для закрытого контура описан в [настройках VM](help:vm-settings).
