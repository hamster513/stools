## Что это

MaxPatrol VM сообщает только, какие [CVE](help:cve) найдены на хосте. Всё остальное о них STools берёт из открытых справочников:

| Справочник | Что даёт |
|---|---|
| [EPSS](help:epss) | вероятность эксплуатации в ближайшие 30 дней |
| NVD CVE (национальная база уязвимостей США) | описание, [CVSS](help:cvss) и вектор атаки; фиды по годам |
| ExploitDB | публичные эксплойты и их тип |
| Metasploit | модули фреймворка и их ранг |
| CISA [KEV](help:kev) | каталог уже эксплуатируемых уязвимостей |
| CVE → ATT&CK от CTID (Center for Threat-Informed Defense, исследовательский центр при MITRE) | какой [технике](help:technique) ATT&CK соответствует CVE — для матрицы, на [риск](help:vm-risk) не влияет |

Первые пять входят в риск. Справочник скачивают из сети, загружают файлом или вместе со всеми одним архивом. После загрузки сведения о CVE пересобираются и риск пересчитывается. Справочник старше 30 дней помечен устаревшим. Если справочника нет, недостающие значения подставляются по умолчанию, и карточка пары это показывает.

## Где встречается в STools

- [Настройки Vulnerability Management](help:vm-settings) — загрузка справочников и скрипты для сети без интернета.
- [О модуле Vulnerability Management](help:vm-overview) — блок «Данные».
- [Данные и загрузки](help:data-status) — свежесть каждого справочника.
