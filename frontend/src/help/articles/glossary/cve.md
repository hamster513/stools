## Что это

CVE (Common Vulnerabilities and Exposures) — общий каталог известных уязвимостей. Каждая уязвимость получает идентификатор вида `CVE-2024-0001`: год и порядковый номер. По этому номеру об одной и той же уязвимости говорят сканеры, производители, базы эксплойтов и бюллетени.

Сам номер о тяжести ничего не говорит. Описание и оценку [CVSS](help:cvss) к нему добавляет национальная база уязвимостей США NVD, вероятность эксплуатации — [EPSS](help:epss), факт эксплуатации в реальных атаках — каталог [KEV](help:kev).

MaxPatrol VM сообщает для каждого хоста список найденных CVE. В STools пара «хост — CVE» — отдельная [находка](help:finding) со своим [риском](help:vm-risk) и статусом: одна и та же CVE на двух хостах — две пары.

## Где встречается в STools

- [Уязвимости](help:vm-vulns) — колонка «CVE», поиск по номеру, карточка с описанием из NVD.
- [О модуле Vulnerability Management](help:vm-overview) — «Уникальных CVE», «CVE, закрывающие больше всего», CVE без записи в NVD.
- [Справочники уязвимостей](help:vm-references) — откуда берутся сведения о CVE.
