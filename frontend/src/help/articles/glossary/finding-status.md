## Что это

Статус показывает, что решено по [находке](help:finding). Статусы одни для всех модулей:

| Статус | Кто ставит | Открытая |
|---|---|---|
| Новая | система, когда находка появилась; человек может вернуть находку в «Новую» | да |
| В работе | человек | да |
| Исправлено | человек: исправили, ждём подтверждения данными | да |
| Принят риск | человек, с обоснованием | нет |
| Ложное срабатывание | человек, с обоснованием | нет |
| Устранена | система: находки нет в свежих данных | нет |
| Переоткрыта | система: находка вернулась в данные | да |

«Исправлено» держится, пока находка есть в данных; когда она пропадёт, система поставит «Устранена». «Принят риск» и «Ложное срабатывание» система не трогает, даже если находка пропала. У принятого риска бывает срок: после него находка снова становится «Новой». Переоткрытая находка сохраняет исполнителя и срок.

Списки находок без фильтра показывают открытые. Какие статусы входят в счётчики модулей, решает администратор платформы.

## Где встречается в STools

- Карточка находки, блок «Работа с находкой» — смена статуса.
- [Мои находки](help:my-findings) — фильтр по статусу.
- [Статусы находок](help:findings-settings) — какие статусы учитываются в подсчётах.
- [Принятие риска](help:risk-accept) — подробнее о статусе «Принят риск».
