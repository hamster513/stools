## Что это

Профиль инсталляции — решения о конкретной установке MaxPatrol SIEM, которые анализатор не может вывести из выгрузки сам и которые принимает человек:

- **какие табличные списки ограничивают область действия правил.** Правило, читающее список критичных узлов, работает только по ним: в матрице ATT&CK оно закрывает технику лишь частично, а пустой список делает его мёртвым. По телу правила это не отличить от списка-справочника, который просто обогащает событие;
- **роли полей:** средовое (значение зависит от инсталляции: узел, учётная запись, адрес) или техническое (значение и есть суть детекта: код события, действие). Литерал в средовом поле — находка; поле без роли не проверяется;
- **встроенные учётные записи**, одинаковые в любой Windows: их имена в правилах находками не считаются;
- **схема именования** правил, из которой берутся автор, категория и группа.

У каждого снапшота свой профиль; пока администратор модуля его не сохранил, он не подтверждён.
