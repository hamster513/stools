## Что это

Оценка домена — число от 0 до 100, которое показывает, насколько плохо дело с [гигиеной](help:ad-hygiene) домена Active Directory: 0 — чисто, 100 — хуже некуда. Чем меньше, тем лучше.

Как она считается:

- Каждая проверка вносит вес своей самой тяжёлой открытой [находки](help:finding), один раз: критическая 40 баллов, высокая 20, средняя 10, низкая 3, справочная 0. Число находок не важно: сто низких находок одной проверки дают те же 3 балла, иначе одна шумная проверка перевесила бы единственную критическую.
- Оценка категории (учётные записи, Kerberos, права на объекты и так далее) — сумма вкладов её проверок, но не больше 100.
- Оценка домена — худшая из категорий.

В расчёт не входят находки из allowlist и находки в [статусах](help:finding-status), которые не учитываются в подсчётах (по умолчанию «[Принят риск](help:risk-accept)», «Ложное срабатывание» и «Устранена»). История оценки по [снапшотам](help:snapshot) статусы не учитывает.

- [Статусы находок](help:findings-settings) — какие статусы входят в подсчёты.
