Сборки 2a17fef, ffa11c4, bf18a1f, b107510 и 70916c7. Первый выпуск, который ставится на сервер из образов. В него вошла платформа с модулями ATT&CK, SIEM Rules Analyzer, Vulnerability Management, Active Directory и новый модуль «Антивирус». Что такое STools целиком — [Что такое STools](help:stools).

## Добавлено

- **Модуль «Антивирус» (KSC).** Импорт выгрузки Kaspersky Security Center и онлайн-сбор по Open API, снапшоты с инвентарём хостов, обзор с [покрытием](help:av-coverage), хосты с фасетами, находки и вердикты, сверка хостов с компьютерами AD. Проверки состояния хостов, политик, задач и лицензий; пороги в настройках. Экран «Сервер KSC»: роли, второй фактор, сертификат, результаты задач, перезагрузки. Содержимое политик защиты с замками. Офлайн-сборщик PowerShell входит с вторым фактором и читает настройки из файла. Подробнее — [Обзор Антивируса](help:ksc-overview).
- **Запуск на сервере.** Образы из реестра, данные в одном каталоге, инструкция установки, лимиты памяти и процессора из настроек окружения.
- **Вход через Avanpost FAM.** Группы из объектов провайдера сопоставляются ролям по имени и идентификатору.

## Безопасность

По итогам аудита: секреты подключений шифруются, токены сессий хранятся хешем, пароль подключения вводится заново при смене адреса; троттлинг входа, проверка Origin, лимиты тела запроса, загрузок и распаковки; TLS-адрес, Secure-cookie, CSP и HSTS, непривилегированные контейнеры; из образа API убран pip, который сканеры находили уязвимым.

## Улучшено

- Страницы находок, задач, снапшотов и подключений модулей AD и антивируса — на общих компонентах платформы, ведут себя одинаково.
- Строки таблиц открываются с клавиатуры, подписи полей связаны с полями.
- Секреты в содержимом политик антивируса скрываются на любой глубине.
