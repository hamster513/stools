## Что это

Подключение к языковой модели (LLM) на сервере Ollama. Модель нужна для двух вещей: предложений по разметке правил SIEM техниками ATT&CK и перевода техник ATT&CK, у которых нет русского текста. Всё остальное в STools работает без неё. Настройка одна на всю платформу: все модули обращаются к модели по одному адресу.

## Как читать

| Поле | Что значит |
|---|---|
| Адрес Ollama | Например `http://ollama.example.local:11434`. Пустой адрес — обычное состояние: исходящих обращений нет, предложения по разметке недоступны |
| Модель выбора техник | Модель, которая предлагает технику ATT&CK для правила |
| Модель эмбеддингов | Отбирает кандидатов; без неё разметка не идёт |
| Таймаут, с | Сколько секунд ждать ответа, от 5 до 1800 |
| Обращения к модели разрешены | Выключатель: адрес остаётся сохранённым, а обращения временно прекращаются |
| Режим рассуждения | Модель рассуждает перед ответом; ответ приходит в разы медленнее |

Наружу уходит только выжимка по группе правил, прошедшая проверку на утечку; тексты самих правил периметр не покидают.

## Как настроить

Страница открыта только администратору платформы; остальные не видят её в меню настроек.

1. Впишите адрес Ollama и имена моделей.
2. Нажмите «Проверить доступность»: STools обратится к модели по адресу из поля, ещё до сохранения, и покажет «модель ответила за N мс» или текст ошибки. Первый ответ после простоя занимает до минуты: модель загружает веса в память.
3. Нажмите «Сохранить».

Где модель используется:

- **SIEM → «Разметка ATT&CK»** — предложения техник для правил корреляции; сколько кандидатов передавать модели, задаётся в «Настройки → SIEM Rules Analyzer».
- **«Настройки → Матрица ATT&CK»** — перевод техник, у которых нет русского текста или чей исходный текст изменился. Перевод запускает человек кнопкой: обращение к модели происходит только по его решению.
