## Что это

Список учётных записей STools: кто может войти, в каких [группах](help:group) состоит и какие права из этого получает. Права человек получает только через группы, поэтому здесь задают, в каких локальных группах он состоит, а уровни доступа настраивают в [ролях](help:access-roles).

## Как читать

| Колонка | Что в ней |
|---|---|
| Логин | Имя для входа |
| Имя | Как человека видят остальные; «—», если не задано |
| Группы | Группы учётной записи; группа из OIDC помечена «OIDC» |
| Вход | «пароль» — вход по паролю STools, «FAM» — через провайдера OIDC |
| Состояние | «активен» или «заблокирован» |
| Последний вход | Дата и время или «не входил» |

Под каждой строкой — «Итоговые права»: [уровень](help:level) в каждом модуле и на платформе, например «SIEM: Аналитик · VM: Аудитор». Области с запретом не перечисляются; если доступа нет нигде, написано «нет доступа». Когда групп несколько, в каждой области действует высший из уровней.

Кнопка «Экспорт» рядом с заголовком сохраняет список в CSV или XLSX; в выгрузке группы перечислены через запятую. Без права менять справа от заголовка стоит подпись «только чтение», а колонки «Действия» нет.

## Как настроить

Менять может только администратор платформы.

**Новый пользователь.** «Добавить пользователя» → логин, имя (пусто — останется логин), пароль не короче 8 символов и локальные группы галочками → «Добавить». Без групп учётная запись войдёт, но доступа ни к чему не получит. Тех, кто входит через провайдера OIDC, заводить не нужно: учётная запись появляется при первом входе, если провайдер передал подходящую группу.

**Действия в строке:**

- «Группы…» — раскрывает под строкой список локальных групп; отметьте нужные и нажмите «Сохранить». Группы из OIDC здесь не меняются: их состав обновляется при входе.
- «сбросить пароль» — задать новый пароль; есть только у учётных записей с входом по паролю. Все сессии пользователя при этом закрываются.
- «заблокировать» и «разблокировать» — заблокированный не может войти, его сессии закрываются.
- «удалить» — после подтверждения; сессии пользователя тоже закрываются.

**Защита от самоблокировки.** Свою учётную запись заблокировать или удалить нельзя, снять с себя права администратора платформы тоже нельзя, и нельзя оставить систему без активного администратора платформы. Такие кнопки серые, а подсказка при наведении объясняет причину: «Себя изменить нельзя» или «Последний администратор». Если запрет обнаружится только на сервере, его текст появится под таблицей.
