## Что это

На одной странице собраны подключения Active Directory и Kaspersky Security Center, Harbor, импорт MaxPatrol VM, справочники уязвимостей, синхронизация активов, DNS, RackTables, база знаний SIEM скачивание матрицы MITRE ATT&CK и замер объёма хранилища. Для каждой задачи можно выбрать свою периодичность. Скачанную матрицу MITRE подтверждают в настройках ATT&CK.

## Как читать

«Вручную» означает, что для источника ещё не задали расписание. «Выключено» сохраняет параметры на будущее. В таблице видны прошлый запуск планировщиком и ближайший ожидаемый запуск. Время указано в часовом поясе сервера.

## Как настроить

Нажмите «Настроить» или «Изменить». Для запуска по дням недели отметьте дни и укажите время. Для интервального запуска задайте от 1 до 720 часов и при необходимости окно. Окно может проходить через полночь. Нажмите «Сохранить расписание».

При временной недоступности планировщика просроченная задача выполняется один раз после возобновления работы. При занятом источнике задача повторяет попытку на следующем тике. Чтобы приостановить задачу, снимите флажок запуска и сохраните расписание. Удаление расписания возвращает источник в ручной режим.

Замер [хранилища](help:storage) доступен при чтении платформы, его расписание меняет администратор платформы. По умолчанию замер включён ежедневно в 03:00. Планировщик Threat Hunting остаётся отдельной частью модуля.
