# Сборщик выгрузки AD для доменной машины

Скрипт `STools-AD-Collector.ps1` скачивается в интерфейсе: Active Directory →
Настройки и данные → «Скачать». Он не анализирует и не меняет ничего в
домене: читает объекты, дескрипторы безопасности, `GptTmpl.inf` политик из
SYSVOL и шаблоны сертификатов и пишет один файл формата `stools-ad/1`
(JSON, gzip).

## Требования

- Windows с PowerShell 5.1 или новее и модулем ActiveDirectory (RSAT).
- Скрипт хранится в UTF-8 с BOM: без него Windows PowerShell 5.1 читает файл в ANSI и ломает кириллицу в строках. При правке сохраняйте BOM (тест `test_collector_script_has_utf8_bom`).
- Учётная запись домена с правами чтения каталога (обычный пользователь
  читает дескрипторы большинства объектов; для `GptTmpl.inf` нужен доступ
  к SYSVOL, он есть у всех доменных пользователей).

## Запуск

```powershell
.\STools-AD-Collector.ps1
.\STools-AD-Collector.ps1 -Server dc01.corp.local -OutputPath C:\Temp\corp.json.gz
.\STools-AD-Collector.ps1 -SkipComputerAcl      # без дескрипторов компьютеров (быстрее)
.\STools-AD-Collector.ps1 -SkipSysvol           # без GptTmpl.inf
```

Результат — `ad-<NETBIOS>-<дата>.json.gz` в текущем каталоге. Файл содержит
инвентарь домена (имена учётных записей, группы, ACL) — обращайтесь с ним
как с чувствительными данными.

## Что дальше

Загрузите файл в STools: Active Directory → Настройки и данные → «Загрузить
выгрузку». Появится снапшот домена; повторные загрузки сравниваются с
предыдущим по времени сбора.

Онлайн-режим (сбор из STools по LDAP) даёт ту же выгрузку — проверки в обоих
режимах одни и те же.
